### 🎧 Что нового в v0.4.56:

#### 1. Стабильность каскадных меню добавления в плейлист
* **Устранение случайного закрытия меню («проблема треугольника»):**
  При движении курсора по диагонали от родительского пункта к всплывающему списку плейлистов внедрён защитный таймер (280 мс). Кратковременное пересечение курсором соседних пунктов главного меню больше не схлопывает открытое подменю.
* **Интерактивный бесшовный мост (Hover Bridge):**
  Между кнопкой вызова и выпадающим окном добавлен невидимый интерактивный мост (14px), исключающий потерю фокуса наведения при перемещении курсора через зазор между панелями.
* **Вынос подменю в корень через React Portal:**
  Все уровни каскадных всплывающих списков теперь монтируются в корень DOM-дерева через `createPortal`, гарантируя изолированный `z-index` (уровень 60), отсутствие коллизий со скроллом и перекрытиями стилей родительских контейнеров.
* **Исправление эффекта смещения из левого верхнего угла:**
  Начальные координаты выпадающих окон теперь предварительно вычисляются синхронно относительно родительского элемента, предотвращая визуальный скачок из координат (0, 0).
