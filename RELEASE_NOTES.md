### 🎧 Что нового в v0.4.30:

#### 1. Чистая обложка плейлиста и оптимизация панели действий
* **Обложка плейлиста:** С обложки плейлиста полностью убран оверлей возврата со стрелкой. Обложка теперь отображается в чистом виде как эстетичный постер без наложения текста и значков при наведении.
* **Постоянная кнопка «Назад»:** Вся навигация назад осуществляется через удобную круглую кнопку «Назад» в стиле Material 3 слева от обложки.
* **Панель действий:** Из верхней панели открытого плейлиста убрана лишняя кнопка удаления — на панели оставлена только главная акцентная кнопка **«Воспроизвести всё»** (`Play All`).

#### 2. Быстрый возврат по клавише Escape (ESC)
* Теперь находясь в открытом плейлисте (или в подробном просмотре альбома/исполнителя/жанра), можно мгновенно вернуться назад к сетке плейлистов простым нажатием клавиши `Escape`.
* Горячая клавиша `Escape` также работает для выхода из папок обратно к корневому списку плейлистов.

#### 3. Плавная анимация сворачивания и разворачивания групп в плейлистах
* Переключение видимости групп («Свернуть / Развернуть») переведено на CSS Grid интерполяцию высоты `grid-template-rows: 0fr <-> 1fr` с физической кривой `cubic-bezier(0.16, 1, 0.3, 1)`.
* Группы теперь открываются и схлопываются мягко, со скользящим плавным поворотом стрелочки-шеврона на 90 градусов, без резких прыжков и рывков содержимого.
