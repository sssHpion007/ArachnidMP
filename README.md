# Arachnid Music Player

Arachnid — настольный музыкальный плеер на React, TypeScript, Rust и Tauri. Интерфейс построен вокруг медиатеки, плейлистов и Material 3.

> **Проект всё ещё находится в активной разработке.** Возможности и интерфейс могут меняться; возможны ошибки и незавершённые сценарии.

## Возможности

- Медиатека с импортом аудиофайлов и папок, поиском и просмотром по трекам, альбомам, исполнителям и жанрам.
- Плейлисты, группы и вложенные папки; очередь воспроизведения, перемешивание и повтор.
- Редактирование тегов, отображение метаданных и обложек.
- Синхронизированные тексты песен: прикреплённая панель, отдельное окно и переход к строке текста.
- Компактный и mini-режимы плеера.
- 10-полосный эквалайзер, визуализатор и Discord Rich Presence.
- Material You (Material 3) — стандартная тема оформления; также доступны полностью настраиваемые пользовательские темы с собственной палитрой и параметрами оформления.
- Портативная Windows-сборка в одном EXE с обновлением из приложения.

## Технологии и планы

Интерфейс: React и TypeScript. Нативная часть: Rust и Tauri. На Windows текущая версия использует WebView2.

В будущем планируется переход с WebView2 на Servo. Это направление дальнейшей разработки, а не возможность текущей версии.

## Запуск и разработка

Требуются Node.js и Rust. Для Windows-сборки также нужны инструменты сборки Windows и WebView2.

```bash
npm ci
npm run dev          # веб-предпросмотр
npm run tauri dev    # приложение Tauri
npm run build        # production-сборка интерфейса
npm run tauri build  # сборка приложения Tauri
```
