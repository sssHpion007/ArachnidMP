# Arachnid Music Player 🎵

> **Современный аудиоплеер с функционалом MusicBee, эстетикой Google Material You 3 и скоростью Tauri 2.0 (Rust).**

---

## 💡 Идея проекта

Плееры вроде **Harmonoid** выглядят современно, но страдают от мобильного UX: нельзя просто перетащить пачку треков в окно, добавление в плейлист требует ручного прокликивания каждого файла, отсутствует нормальное выделение.
С другой стороны, **MusicBee** остаётся королём по возможностям (пакетный теггинг, плейлисты, горячие клавиши, гибкая библиотека), но его интерфейс морально устарел.

**Arachnid** объединяет лучшее из обоих миров:
* Мощнейший десктопный UX в духе MusicBee (Drag & Drop, Shift/Ctrl мультиселект, пакетная правка тегов, сайдбар с плейлистами).
* Чистая и плавная эстетика **Material You 3** с динамическим извлечением палитры цветов прямо из обложек треков.
* Встроенный **Discord Rich Presence (RPC)** с отображением трека, исполнителя, обложки и времени прослушивания.
* Низкое потребление памяти (~40–60 МБ RAM) благодаря ядру на **Rust (Tauri 2.0)**.

## ✨ Ключевой функционал

### 1. Десктопный UX без компромиссов
* **Перетаскивание файлов прямо в окно (Drag-and-Drop):** закиньте файлы MP3, FLAC, WAV, OGG, M4A в любое место окна — они мгновенно добавятся в библиотеку с автоматическим извлечением ID3-тегов и обложек.
* **Честное множественное выделение:**
  * `Shift + Клик` — выделение диапазона треков.
  * `Ctrl / Cmd + Клик` — точечное добавление/удаление из выделения.
  * `Ctrl / Cmd + A` — выделить все треки.
* **Плавающая панель групповых действий:** при выделении нескольких треков появляется панель быстрого воспроизведения, добавления в очередь или пакетной правки.
* **Перетаскивание на плейлисты:** выделите треки и просто перетащите их на название плейлиста в левом сайдбаре.

### 2. Пакетный редактор тегов (MusicBee Tag Editor)
* Выделите любое количество треков → правый клик или кнопка на панели → «Редактировать теги».
* За один клик меняйте Исполнителя, Альбом, Жанр или Год для всей подборки.

### 3. Material You 3 Динамическая Темизация
* **Dynamic Palette:** плеер автоматически считывает доминирующие цвета из обложки текущего альбома и плавно перекрашивает акценты интерфейса (фоны, слайдеры, кнопки).
* **3 режима отображения:**
  * **Dark (Тёмная тема)** — классический Material 3 с глубокими тонами.
  * **AMOLED Pure Black** — абсолютный чёрный для OLED-дисплеев.
  * **Light (Светлая тема)** — чистый минималистичный светлый интерфейс.
* Возможность зафиксировать постоянный акцентный цвет (Deep Violet, Emerald, Electric Blue, Sunset Amber, Rose).

### 4. Discord Rich Presence (RPC)
* Нативная интеграция активности в Discord:
  * Название трека и альбома
  * Исполнитель
  * Точное прошедшее время и таймкод
  * Статус (Playing / Paused)
  * Интерактивная карточка предпросмотра в настройках.

### 5. Аудиодвижок и эквалайзер
* 10-полосный графический эквалайзер (32 Гц – 16 кГц) с пресетами: *Flat, Bass Boost, Treble Boost, Rock, Electronic, Vocal, Jazz*.
* Анимированный спектральный визуализатор в реальном времени.
* Управление очередью воспроизведения (Now Playing Queue) с перемешиванием и изменением порядка.

## 🛠 Технологический стек

* **Frontend:** React 18, TypeScript, Tailwind CSS, Colord (HCT / Material Design 3 алгоритмы), Lucide Icons, Music-Metadata.
* **Desktop Core:** Tauri 2.0 (Rust)
  * `lofty` — нативный парсер и редактор аудиотегов
  * `discord-presence` — интеграция с Discord IPC через локальный сокет
  * `walkdir` — мгновенное сканирование музыкальных папок

## 🚀 Запуск и разработка

### Веб-разработка (быстрый предпросмотр):
```bash
# Установка зависимостей
npm install

# Запуск локального сервера разработки
npm run dev
```

### Сборка десктопного приложения (Tauri 2.0):
```bash
# Режим разработки Tauri с нативным окном
npm run tauri dev

# Сборка готового инсталлятора (.exe, .deb, .dmg)
npm run tauri build
```
